# AI

Bagian ini merangkum tools AI yang relevan untuk kerja teknikal: eksplorasi ide, drafting, analisis, dan automasi ringan.  
Rujukan di sini diposisikan sebagai **alat bantu berpikir**, bukan substitusi judgment engineer.

## Ruang Lingkup

- LLM platforms (chat, API, workspace)
- Prompt workflow & evaluasi
- Dev tools untuk integrasi AI
- Catatan etika dan batasan penggunaan

## Cara Membaca Rujukan Tool

Setiap tool (jika ditulis) akan memuat:

- **Kapan relevan** (use-case)
- **Kapan tidak relevan** (anti use-case)
- **Batasan** (akurasi, biaya, privasi)
- **Alternatif** (open-source / manual approach)
