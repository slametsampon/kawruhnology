- Pemula absolut
- Belajar sintaks Arduino dasar
- Hanya membuat demo cepat

# 🧭 Struktur Dua Track

Course dibagi menjadi:

### 🔹 Track 1 — Foundation (Mental Model & System Thinking)

### 🔹 Track 2 — Production (Discipline & Freeze Architecture)

Foundation menjawab **“mengapa”**
Production mengunci **“bagaimana”**

---

# 🗓 12–16 Week Roadmap

Struktur fleksibel:

- 12 minggu intensif
- 16 minggu dengan lab & audit lebih dalam

---

# 🔹 PHASE 1 — FOUNDATION (Week 1–8)

---

## Week 1 — ESP32 Execution Reality

**Materi:**

- Arduino core di atas FreeRTOS
- loop() sebagai task
- Dual-core awareness
- ISR preemption
- Watchdog overview

**Lab:**

- Observasi blocking behavior
- Eksperimen delay vs non-blocking

**Outcome:**
Engineer memahami bahwa sistem bersifat preemptive.

---

## Week 2 — RTOS & Concurrency Fundamentals

**Materi:**

- Scheduler
- Task state
- Race condition
- Shared mutable state
- Queue concept

**Lab:**

- Simulasi race condition
- Event via queue

**Outcome:**
Engineer memahami risiko shared state.

---

## Week 3 — FreeRTOS Execution Model (ESP32 Specific)

**Materi:**

- loopTask
- Core mapping
- Stack per task
- Heap vs stack
- Context switch cost

**Lab:**

- Stack overflow simulation
- Monitoring free heap

**Outcome:**
Engineer memahami batas nyata resource.

---

## Week 4 — Memory Model & Object Lifetime

**Materi:**

- Heap fragmentation
- Object lifetime alignment
- Static vs dynamic allocation
- Hidden allocation di C++

**Lab:**

- Fragmentation experiment
- Allocation stress test

**Outcome:**
Engineer memahami memory sebagai constraint sistem.

---

## Week 5 — OOP for Embedded Firmware

**Materi:**

- Encapsulation sebagai boundary
- Constructor & lifecycle
- Composition vs inheritance
- Ownership clarity

**Lab:**

- Refactor procedural → class-based

**Outcome:**
Engineer memahami OOP sebagai alat kontrol.

---

## Week 6 — 3-Layer Firmware Architecture

**Materi:**

- Application layer
- Service layer
- Driver layer
- Dependency direction

**Lab:**

- Implementasi `IndustrialNode` 3-layer penuh

**Outcome:**
Firmware terstruktur secara sistemik.

---

## Week 7 — Communication & State Thinking

**Materi:**

- Callback hazard
- State machine
- Transport vs business logic
- Reconnect behavior

**Lab:**

- Implement simple state machine
- Simulasi broker restart

**Outcome:**
Engineer memahami komunikasi sebagai domain stateful.

---

## Week 8 — Reliability & Transition Thinking

**Materi:**

- Fail-safe
- Observability
- Watchdog perspective
- Error containment

**Lab:**

- Simulasi sensor failure
- Safe-state enforcement

**Outcome:**
Engineer memahami reliability sebagai desain.

---

# 🔹 PHASE 2 — PRODUCTION (Week 9–16)

---

## Week 9 — Dependency Discipline Freeze

- No global mutable
- Constructor injection
- Composition enforced
- No singleton

**Audit Exercise**

---

## Week 10 — Memory Discipline Freeze

- Allocation policy
- No dynamic in control path
- Heap monitoring baseline

**Audit Exercise**

---

## Week 11 — Layering Enforcement

- DAG dependency
- Include direction
- Circular detection

**Refactor Lab**

---

## Week 12 — Concurrency Boundary

- Task-per-domain rule
- ISR boundary
- Queue encapsulation

**Stress Test Lab**

---

## Week 13 — Communication Architecture Freeze

- CommManager centralization
- State machine formalization
- Offline-safe policy
- Credential isolation

**Network Failure Simulation**

---

## Week 14 — Reliability & Error Model Freeze

- Explicit error enum
- No exception
- Fail-safe mandatory
- Logging abstraction
- Health telemetry

**Failure Injection Lab**

---

## Week 15 — Anti-Pattern Audit

- Virtual abuse
- Hidden allocation
- Template overengineering
- Singleton risk

**Code Review Drill**

---

## Week 16 — Final Production Audit

Checklist validation:

- Dependency clean
- Heap stable
- Stack safe
- Communication isolated
- Fail-safe enforced
- No architectural drift

Capstone:
Deploy node with 7-day stability test.
