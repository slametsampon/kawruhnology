# 📐 Boundary Rule Monetisasi Kawruhnology

Dokumen ini menetapkan **batas monetisasi berbasis kategori DAN karakter judul konten**, bukan asumsi abstrak.
Jika suatu konten melanggar salah satu aturan di bawah, **monetisasi otomatis gugur**.

---

## 🔒 KATEGORI YANG TIDAK AKAN PERNAH DIMONETISASI

### 1️⃣ `religy` — ❌ ZERO MONETIZATION (MUTLAK)

**Karakter konten (contoh tipikal):**

- Tafsir
- Renungan ayat
- Nilai keimanan
- Refleksi spiritual

**Aturan tegas:**

- Tidak ada affiliate link
- Tidak ada rujukan platform, tools, buku berbayar
- Tidak ada CTA berbentuk tindakan ekonomi

📌 **Alasan utama:**
Konten ini menyentuh **niat, iman, dan keikhlasan**. Monetisasi = konflik nilai.

---

### 2️⃣ `motivasi` — ❌ ZERO MONETIZATION

**Karakter konten:**

- Penguatan mental
- Refleksi hidup
- Dorongan moral

**Aturan:**

- Tidak boleh diarahkan ke produk, course, tools produktivitas
- Tidak ada “solusi berbayar” atas masalah personal

📌 **Prinsip:**
Motivasi tidak boleh menjadi _sales funnel emosional_.

---

### 3️⃣ `general` — ❌ ZERO MONETIZATION

**Contoh file nyata:**

- `laju-alir-air.mdx`

Meski terlihat teknis, konten ini:

- Bersifat edukatif dasar
- Tidak mengarah ke stack / tool / platform spesifik

**Aturan:**

- Tidak ada monetisasi, meski topiknya “teknis ringan”
- Tetap murni sebagai _knowledge explainer_

---

### 4️⃣ `markdown` — ❌ ZERO MONETIZATION

**Karakter:**

- Dokumentasi format
- Catatan teknis murni
- Referensi penulisan

📌 **Alasan:**
Ini adalah **infrastruktur pengetahuan**, bukan ruang rekomendasi.

---

## 🟡 KATEGORI DENGAN PEMBATASAN KETAT (CONTEXT-ONLY)

### 5️⃣ `agri` — ⚠️ NON-KOMERSIAL PRAKTIK

**Contoh file nyata:**

- `airlift-pump.mdx`
- `akuaponik-modul.mdx`
- `akuaponik-praktis.mdx`
- `hidroponik-vertikal-indoor.mdx`
- `hidroponik-vertikal-outdoor.mdx`
- `bio-filter.mdx`
- `pH.mdx`

**Aturan:**

- ❌ Tidak boleh marketplace
- ❌ Tidak boleh produk fisik
- ❌ Tidak boleh “alat beli di sini”
- ✔️ Boleh penjelasan konsep, metode, eksperimen

📌 **Catatan penting:**
Walau _potensial secara afiliasi_, kategori ini **sengaja dikunci** agar tidak berubah jadi blog jualan alat tani.

---

### 6️⃣ `Bisnis` — ⚠️ IDE & REFLEKSI SAJA

**Contoh file nyata:**

- `freelancer.mdx`

**Aturan:**

- Tidak ada tools bisnis berbayar
- Tidak ada platform monetisasi
- Fokus pada _cara berpikir_, bukan _alat menghasilkan uang_

📌 **Prinsip:**
Bisnis dibahas sebagai **kerangka keputusan**, bukan jalan pintas ekonomi.

---

## 🟢 KATEGORI YANG BOLEH DIMONETISASI (DENGAN ETIKA & ISOLASI)

> Dicantumkan untuk kejelasan batas, **bukan izin otomatis**

---

### 7️⃣ `AI` — 🟢 POTENSIAL TERKUAT

**Contoh file nyata:**

- `artikel-ai.mdx`
- `platform-ai.mdx`
- `prompt-engineering.mdx`

**Aturan:**

- Monetisasi **tidak inline**
- Rujukan diarahkan ke `/tools`
- Artikel tetap edukatif & kritis

✔️ Ini kategori **paling natural** untuk afiliasi berbasis rujukan.

---

### 8️⃣ `IoT` — 🟢 TEKNIKAL SAH

**Contoh file nyata:**

- `dataModelHortiLink.mdx`
- `esp32.mdx`
- `HortiLink.mdx`
- `iot.mdx`
- `tahap1.mdx`
- `tahap3.mdx`
- `web-server-esp.mdx`

**Aturan:**

- Boleh platform cloud / dashboard / infra
- Tidak boleh hardware marketplace
- Fokus pada _arsitektur & konsep_

---

### 9️⃣ `website` — 🟢 AMAN & RELEVAN

**Contoh file nyata:**

- `deploying-next-apps.mdx`

**Aturan:**

- Hosting, deployment, analytics boleh
- Tidak boleh spam SaaS
- Rujukan harus _experience-driven_

---

### 🔟 `teknologi` — 🟢 TERBATAS & KONTROLLED

**Contoh file nyata:**

- `drone-pertanian.mdx`

**Aturan:**

- Tidak otomatis boleh dimonetisasi
- Harus dicek: edukasi vs produk
- Jika condong ke alat fisik → **diblok**

---

### 1️⃣1️⃣ `kompetensi` — 🟢 LEARNING-ORIENTED

**Contoh file nyata:**

- `bertanya.mdx`
- `literasi.mdx`
- `micro-question-management.mdx`
- `prepare-for-success.mdx`
- `saran-kritik.mdx`

**Aturan:**

- Course / learning platform boleh (fase lanjut)
- Tidak boleh motivasi palsu
- Tetap fokus ke _skill & cara berpikir_

---

## 🧱 ATURAN GLOBAL PENGUNCI

1. **Judul reflektif = no monetization**
2. **Topik spiritual / emosional = steril**
3. **Jika satu artikel ragu → batal monetisasi**
4. **Boundary rule > peluang komisi**
5. **Tidak ada monetisasi retroaktif**

---

## 🧠 PENUTUP

Dengan struktur konten riil yang Anda miliki sekarang, keputusan ini:

- **Melindungi identitas Kawruhnology**
- Menghindari “affiliate creep”
- Menjaga trust pembaca lama
- Menyiapkan fondasi afiliasi yang _bermartabat_

📌 Kawruhnology **tidak anti-monetisasi**,
tetapi **anti kehilangan arah**.
